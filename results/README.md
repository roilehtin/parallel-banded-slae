# Фактические результаты

- Интерактивная проверка: Slurm `9059902`, узел `n06p003`.
- Pthreads/OpenMP: Slurm `9059936`, раздел `cascade`, до 48 потоков.
- C + MPI: Slurm `9059919`, раздел `tornado`, до 112 процессов.
- Python + MPI: Slurm `9059920`, раздел `tornado`, до 112 процессов.

Все реализации прошли допуск `1e-10`. Лучшее время OpenMP - 0.0517 с на
8 потоках (`S=3.80`); лучшее время C + MPI - 0.0578 с на 28 процессах
(`S=2.92`). Полные строки измерений находятся в `benchmark.csv`.
